# varunj.com

Personal blog built with [Hugo](https://gohugo.io/) and the [Shibui](https://github.com/ntk148v/shibui) theme. Deployed to [GitHub Pages](https://pages.github.com/) at [varunj.com](https://varunj.com).

## Local Development

```bash
# Clone with submodules
git clone --recurse-submodules https://github.com/fret423/varunj.git

# Run dev server
hugo server -D
```

## New Post

```bash
hugo new content content/posts/my-post.md
```

Edit the file, commit, and push to `main`. The site auto-deploys via GitHub Actions.
